# Jhomer Palacios — Personal Web Portfolio

A responsive HTML, CSS, and JavaScript portfolio starter based on the CSIT 111 Activity 9 requirements.

## Files
- `index.html` — page content and six required portfolio sections
- `style.css` — dark navy/blue styling and mobile responsive layout
- `script.js` — mobile navigation, current year, and scroll reveal animation
- `profile.jpg` — optional profile photo (add your own image with this exact filename)

## Run in Visual Studio Code
1. Extract the ZIP file.
2. Open the extracted `Jhomer_Personal_Portfolio` folder in VS Code.
3. Open `index.html` in a browser, or install the **Live Server** extension.
4. If using Live Server, right-click `index.html` and choose **Open with Live Server**.

## Personalize before submitting
- Replace `profile.jpg` with your own suitable profile photo.
- Add your Senior High School name, strand, graduation year, and expected college graduation year.
- Replace achievement placeholders with real achievements or remove entries that do not apply.
- Check that listed skills reflect what you can demonstrate.
- Update the project cards to match your actual completed work and add screenshots or links if available.
- Replace `your-email@example.com` in `index.html` with your preferred contact email, or remove the contact button if you do not want to publish an email address.

The two project cards are starter examples based on the student's previously discussed schoolwork. Confirm they accurately represent work you completed before submitting.
